# Wa Yee Siong — Finance & Quantitative Portfolio

A recruiter-facing portfolio for selected finance, investment analysis, econometrics and data-analytics projects.

## Files

- `index.html` — master portfolio page
- `project-exchange-rate.html` — detailed financial econometrics case study
- `styles.css` — shared visual styling
- `assets/exchange-rate-volatility-export-growth-malaysia.pdf` — full academic report
- `assets/favicon.svg` — site icon

## Publish with GitHub Pages

1. Create a public GitHub repository, e.g. `portfolio`.
2. Upload all files and folders in this directory. Keep `index.html` in the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.
6. GitHub will generate a public site URL such as `https://YOURUSERNAME.github.io/portfolio/`.

## Before publishing

Add your LinkedIn and GitHub URLs once they are ready. Review every source file for confidential, proprietary or personally sensitive information before making the repository public.

## Adding another project

1. Duplicate `project-exchange-rate.html` and rename it.
2. Replace the content with the new project's objective, tools, methodology, findings and source links.
3. Add a new project card to the `#projects` section in `index.html`.
4. Add any supporting PDF, Excel or presentation files under `assets/`.
