01

Problem

Brokerage platforms provide account balances and transaction records, but investors may still need to manually reconstruct portfolio cost basis, evaluate actual investment performance and calculate quantitative risk measures.

How can raw brokerage trade data be converted into a reusable portfolio analytics workflow?

I built this application to automate that process using Python, combining trade-level transaction data with market prices, benchmark data and foreign-exchange rates.

02

Solution

The application allows a user to upload a Moomoo trade-export CSV and automatically reconstructs the portfolio before generating performance and risk analytics.

1

Upload Trades

Import executed brokerage transactions directly from a CSV export.

2

Reconstruct Portfolio

Process purchases and sales chronologically using weighted-average cost.

3

Generate Analytics

Calculate portfolio performance, market risk and benchmark-relative statistics.

03

Application Architecture

The project separates the financial calculation engine from the Streamlit interface so that the portfolio methodology has a single source of truth.

1

Moomoo Trade Export

The user uploads executed transaction history in CSV format.

2

Data Cleaning & Validation

The program validates required fields, cleans numeric values and identifies the market associated with each security.

3

Portfolio Engine

Python reconstructs positions, cost basis, realized P/L, foreign-currency exposure and investor cash flows.

4

Market Data

Historical asset prices, benchmark data, Treasury yields and FX rates are retrieved for the quantitative analysis.

5

Analytics Engine

The application calculates investor performance, historical return, volatility, beta, Sharpe ratio and Jensen's alpha.

6

Dashboard & Export

Results are displayed interactively in Streamlit and can also be exported into a structured Excel report.

04

Trade-Level Portfolio Accounting

One of the main challenges was correctly reconstructing the remaining cost basis after multiple purchases and partial sales.

WAC

Weighted-Average Cost

Purchases increase the remaining cost basis while sales remove the average cost associated with the shares sold.

P/L

Realized vs. Unrealized

Completed sales are separated from gains or losses on securities still held.

Fees

Transaction Costs

Brokerage fees are incorporated into purchase cost and sale proceeds where available.

05

Actual Investor Performance

The application separates actual investor performance from historical portfolio-model estimates.

Metric Purpose
Current Market Value Current USD value of active holdings.
Unrealized P/L Gain or loss on positions that remain open.
Realized P/L Gain or loss crystallized through completed sales.
Estimated Dividends Estimated dividend income based on historical holding quantities.
Money-Weighted Return XIRR based on the amount and timing of investor cash flows.
06

Historical Risk & Return Analytics

Current portfolio weights are applied to historical asset returns to estimate how the current allocation has behaved over the selected historical period.

σ

Volatility

Measures annualized total portfolio risk using the covariance structure of the holdings.

β

Beta

Measures sensitivity of portfolio returns relative to the selected benchmark.

S

Sharpe Ratio

Evaluates excess historical return per unit of total risk.

α

Jensen's Alpha

Compares portfolio return with the return implied by CAPM.

09

Data Validation

Financial analytics can become misleading when transaction history is incomplete, so the application performs validation before calculating portfolio statistics.

Required Fields Checks whether the required trade-export columns are available.
Incomplete Trade History Detects situations where recorded sales exceed reconstructed holdings.
Market Data Raises warnings when required historical market or foreign-exchange data are unavailable.
Short Samples Warns when overlapping historical observations are insufficient for stable risk estimation.
10

Limitations

Historical estimation Past return, volatility and correlation may not represent future market behaviour.
Market-data source Yahoo Finance data may differ from official brokerage statements or exchange data.
Dividend estimation Dividend income is estimated and may not capture withholding taxes or broker-specific adjustments.
Transaction completeness XIRR and cost-basis calculations depend on complete trade history.
Short positions The current version focuses on long-only portfolio analytics.
